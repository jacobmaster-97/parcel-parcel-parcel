# 街坊集運 · Parcel Parcel Parcel

像素風集運自提點經營原型，支援鍵盤與手機觸控。

**[立即遊玩 v0.8](https://jacobmaster-97.github.io/parcel-parcel-parcel/?v=0.7)**

每個營業日150秒（2分30秒），接待後按提貨碼找貨，亦有寄貨客人及送貨員。新貨自由選架上架；桌面WASD／方向鍵移動、E互動、Esc暫停；手機搖桿及互動按鈕。

關店後：收支摘要→自提點升級（可跳過）→不限時貨物上架→保存→下一天。整理時可重開商店，零收貨亦先提供升級機會。

| 升級 | 價格與效果 |
| --- | --- |
| 工作鞋 | $80，移速80→88，當晚及接下來3個營業日有效，不疊加 |
| A/B貨架 | 各自4→6格$480，6→8格$650 |
| 新增C／D區 | $320取得4格，之後同價加層至8格；C在原右側位置，D在下方新一排 |
| 收／寄貨籠 | 各自每次$200加2格，最高12格 |
| 理貨店員 | $60／營業日，夜間預約翌日、先預留，翌日扣一次；不自動續聘。可選允許分區及優先區，只上架 |

新店$0，提貨$10加小費$0–5，寄貨入籠$12。收入及累計營收與投資／薪金支出分開。分店及自取櫃暫緩，店員自動提貨屬後期；沒有真實付費、貸款或離線收益。

**只在整理完、準備開下一天前自動保存。** 購買、營業、暫停、日結及整理中不自動保存。中途關頁回到上次成功保存點，未保存購買／收入／庫存一起回退；可先手動匯出JSON。讀檔先暫停，離線時間不走。同瀏覽器同網站保存，跨裝置用匯入／匯出，清除網站資料需下載備份恢復。

v0.5有效存檔可繼續，初始升級為Lv0，原有錢及貨物保留。主檔及有效備份、原生交易與單分頁寫入保護均保留。

## 翌日事件（v0.8）

關店後，現有升級詢問先預告翌日店況，商店及暫停頁可查看；只在開下一天前保存，重開面板／匯出／重試／重載不重抽或二次套倍率。

| 事件 | 客流 | 收貨頻率 | 客人耐性 | 原始權重 |
| --- | --- | --- | --- | --- |
| 平常一天 | 不變 | 不變 | 不變 | 70 |
| 購買網優惠 | 提貨／寄貨+50% | +60% | −40% | 20 |
| 惡劣天氣 | 不變 | −40% | 不變 | 5 |
| 退貨潮 | 寄貨+50%，提貨基準不變 | 不變 | −20% | 5 |

第1天正常，第4天才加入優惠高峰；優惠／退貨連續兩日後安排正常／天氣日。候選過濾後權重正規化。頻率指生成嘗試，隊長、貨物與格位限制保留，不保證實際收入按比例增加。營業150秒、速度及基本服務費不變；小費仍按耐性公式。練習不套事件。

舊schema1/2/3存檔當天維持正常，保留原派客／送貨計時及耐性，下一個關店才開始預告。詳細規則見[事件實作規則](design/random-events-v1/IMPLEMENTED.md)。
