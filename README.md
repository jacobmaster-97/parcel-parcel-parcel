# 街坊集運 · Parcel Parcel Parcel

像素風集運自提點經營原型，支援鍵盤與手機觸控。

**[立即遊玩 v0.5](https://jacobmaster-97.github.io/parcel-parcel-parcel/?v=0.5)**

每個營業日180秒，接待客人後按提貨碼找貨，亦有寄貨客人及送貨員。新貨自由選A/B/C貨架，收舖後不限時整理。桌面WASD／方向鍵移動、E互動、Esc暫停；手機搖桿及互動按鈕。

v0.5加入跨日錢包、收支日報、本地保存、JSON匯入／匯出與備份恢復。新店$0；提貨$10加小費$0–5，寄貨入籠$12；練習獨立。尚無可購買升級或離線收益。

**只在整理完、準備開下一天前自動保存。** 營業、暫停、日結及整理中不自動保存。中途關頁會回到上次成功保存點；第一天尚未保存時沒有可續玩的主檔，可先手動匯出JSON。讀檔先暫停，離線期間時間不走。同瀏覽器同網站保存，手機與電腦不自動同步，轉移用匯出／匯入。清除網站資料會同時清除本地備份。

```sh
npm start
npm test
npm run build
```

Node.js 20+，遊戲執行期無外部套件。Pages使用main的/docs，docs/index.html為自包含單檔。PROTOTYPE.md說明玩法及保存契約，QA_REPORT.md列測試與限制。規則43項及桌面／手機尺寸Chromium測試通過；Android／iPhone真機及Safari仍待驗證。

美術與既有地圖保留，原始碼及打包工具均在此倉庫。回滾可revert對應提交，再讓Pages重建；不需刪除本地存檔。
