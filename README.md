# 街坊集運 · Parcel Parcel Parcel

像素風集運自提點經營遊戲，支援鍵盤及手機觸控。

**[立即遊玩 v0.19.3](https://jacobmaster-97.github.io/parcel-parcel-parcel/?v=0.19.3)**

每個營業日2分鐘。接待客人取得提貨碼，找貨交付；亦可接收寄貨、自由上架，並聘用理貨員協助。新店先有A/B貨架，C/D及容量可購買升級；未購入貨物管理系統前需逐架找貨。

關店流程：收支摘要 → 明日店況及商店升級 → 不限時貨物上架 → 保存 → 下一天。手機只設完整地圖，頂部工作簡列可展開詳情，操作區獨立。

## 成就（v0.19共31項）

31項成就及31款原風格像素圖示，涵蓋提貨、寄貨、上架、技巧、升級、團隊、事件及收支。未達成只顯示問號，首階達成才揭示專屬圖示；銅／銀／金共用同一張卡，不新增數值獎勵。

入口：主選單「成就」、暫停選單「成就」、關店摘要「查看成就」。返回原入口，暫停不會自行恢復。清單沒有狀態／分類篩選欄，直接展示全部成就。

詳見 [實裝規則](design/achievements-v1/IMPLEMENTED.md) 及 [UI審核](design/achievements-v1/UI_AUDIT.md)。

音樂、音效及文字偏好會獨立記住在目前瀏覽器，不隨遊戲備份覆蓋。返回設定後仍暫停，按「繼續當值」才恢復。

## 操作與保存

- 桌面：WASD／方向鍵移動，E互動，選貨後確認，Esc返回／暫停。
- 手機：左下搖桿、右下情境按鈕；點包裹再確認。查看工作詳情仍計時，需停下可按暫停。
- 只在整理完成、準備開下一天前自動保存。中途關頁，未保存收入、購買、貨物及成就一起回到上次完整保存點。
- 暫停及收舖頁可手動匯出JSON備份；同瀏覽器、同網站保存，跨裝置用匯出／匯入，沒有雲端同步或離線收益。
- schema11支援舊1–10存檔。舊檔只補認可靠收入／已購設備／實際付薪，不編造缺失服務及玩家／AI上架數量。

## 開發及驗證

Node.js20+，遊戲執行期不需外部套件。

```sh
npm start
npm test
npm run build
```

本地 http://127.0.0.1:4173。Pages使用main的/docs；docs/index.html為自包含單檔，版本及SHA見docs/version.json。

111項規則測試通過。成就三入口與五尺寸、完整鍵盤／觸控、選貨往返、原生存檔故障及分頁擁有權、手機16版面、五尺寸離線回歸通過。驗證使用Chromium模擬；Android／iPhone／Safari真機、讀屏及長期平衡未驗。

更新／回退先匯出完整備份。舊版程式不能讀較新schema11；回退v0.18須保留原schema10備份，不合併兩份分支。
