## 操作與保存

- 桌面：WASD／方向鍵移動，E互動，選貨後確認，Esc返回／暫停。
- 手機：左下搖桿、右下情境按鈕；點包裹再確認。查看工作詳情仍計時，需停下可按暫停。
- 只在整理完成、準備開下一天前自動保存。中途關頁，未保存收入、購買、貨物及成就一起回到上次完整保存點。
- 暫停及收舖頁可手動匯出JSON備份；同瀏覽器、同網站保存，跨裝置用匯出／匯入，沒有雲端同步或離線收益。
- schema11支援舊1–10存檔。舊檔只補認可靠收入／已購設備／實際付薪，不編造缺失服務及玩家／AI上架數量。
