# NPC對白：v0.12 實裝紀錄

2026-10-24香港。使用者明確要求按更新提案實裝，原「等待確認」已解除。內容沿用v2全部32句：客人12、理貨員8、送貨員12，不改句子。

## 節奏與狀態

- 全店營業中的有效對白時間每12–20秒嘗試一次，最多一則，顯示最多2.5秒；同一角色至少30秒冷卻，盡量不連續重複同句。對白不保證每次有人說，也不強制送貨員每個階段發言。
- 暫停、選貨／管理視窗、保存中、擁有權喪失或非營業狀態不說話。暫停及選貨凍結對白計時；原本選貨仍消耗營業時間／耐性的規則不變。關店清掉氣泡，翌日重設等待。新店／載入／恢復正式進度重新等待12–20秒，不重播舊對白。
- 客人依提／寄、耐性比例及成功離店選句；低耐性不說「唔急」。只有本次實際完成交接的離店客可說感謝，超時或關店離開不說成功句。
- 理貨員依持貨、可用的允許分區空位、庫存及當日優惠選句。有正在執行且已預留目的格的任務，不會誤說沒位；真正無可用位待命才可說W07。
- 送貨員持貨進店／途中、缺少本批兩格空位而waiting、已卸貨／空手離店及事件逐一過濾。持貨折返不說送完；卸貨句只在空手且接近收貨區的離場階段，沒有重播卸貨或加貨事件。

## 畫面與無障礙

氣泡是短暫Canvas介面，延續深青邊框／米白底，不增加常駐HUD。先試頭上，再試左右／下方及較低側邊；保護所有人物、櫃檯、活動門、架／籠、收寄貨標籤、互動浮標及實際可見的E提示。字級至少14 CSS px；桌面／模擬手機實測20／15 px，長句換行，不以縮字解決擁擠。量測按字級快取。

只讓整個角色在畫面內、且該句有安全位置時參加抽選。若移動後找不到空位，氣泡隱藏；不把文字堆到邊角或蓋住包裹。尾端方向依角色位置調整，氣泡留在裁切範圍內。Canvas沒有新增點擊事件，氣泡不可攔截搖桿／互動按鈕。

同一句只在開始時更新隱藏的polite live status，提供角色稱呼及文字；未加入語音或其他聲音。實際讀屏表現尚未真機驗證。
